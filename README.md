## Commands & Examples

1. Voting Eligibility (If-Else)
   - **Description**: Checks if a user is eligible to vote based on age using if-else.
   - **Usage**:
     - gcc voting.c -o voting
     - ./voting
   - **Purpose**: Demonstrates basic if-else condition handling in C.

2. Voting Eligibility (Ternary Operator)
   - **Description**: Uses the ternary operator to check voting eligibility.
   - **Usage**:
     - gcc voting.c -o voting
     - ./voting
   - **Purpose**: Demonstrates conditional expressions using ternary operator.

3. Day of the Week (Switch Case)
   - **Description**: Maps a number (1–7) to the corresponding weekday.
   - **Usage**:
     - gcc switch.c -o switch
     - ./switch
   - **Purpose**: Practice using `switch` statements with valid/default cases.

4. Life Path Number (Switch Case + Arithmetic)
   - **Description**: Calculates the life path number based on birth date and gives a short astrology insight.
   - **Usage**:
     - gcc switch.c -o switch
     - ./switch
   - **Purpose**: Combines arithmetic operations and `switch` to deliver user-specific output.

5. Print 1 to 5 (While Loop)
   - **Description**: Prints numbers from 1 to 5 using a `while` loop.
   - **Usage**:
     - gcc while.c -o while
     - ./while
   - **Purpose**: Simple demonstration of loop structures in C.

6. Fibonacci Series
   - **Description**: Generates the Fibonacci sequence up to a user-defined number.
   - **Usage**:
     - gcc fibonacci.c -o fibonacci
     - ./fibonacci
   - **Purpose**: Understand iterative logic to generate sequences.

7. Factorial of a Number
   - **Description**: Calculates factorial of a non-negative integer using a `for` loop.
   - **Usage**:
     - gcc factorial.c -o factorial
     - ./factorial
   - **Purpose**: Practice loop logic and factorial computation.

8. Binary to Decimal Conversion
   - **Description**: Converts a binary number (entered as an integer) to its decimal equivalent.
   - **Usage**:
     - gcc binary.c -o binary
     - ./binary
   - **Purpose**: Demonstrates number system conversion using loop and arithmetic.

9. Find Max and Min in Array
   - **Description**: Takes an array input from user and finds maximum and minimum elements.
   - **Usage**:
     - gcc array.c -o array
     - ./array
   - **Purpose**: Practice array input/output and comparison logic.
