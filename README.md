# IT2244-Operating-Systems
# Message Queue Communication in C

## Description
This project demonstrates **Inter-Process Communication (IPC)** using **System V Message Queues** in C. It includes two C programs:

- `sendmsg.c`: Sends a message to a message queue.
- `recmsg.c`: Receives a message from the message queue.

These programs use a shared key generated by `ftok()` and communicate through a message queue created using that key.

## Commands & Examples

### 1. sendmsg.c
- **Description**: Sends a text message to a System V message queue.
- **Usage**:
  ```bash
  gcc sendmsg.c -o sendmsg
  ./sendmsg
  ```
- **Purpose**: Writes a message into the message queue for another program to read.

### 2. recmsg.c
- **Description**: Receives a message from the System V message queue and displays it.
- **Usage**:
  ```bash
  gcc recmsg.c -o recmsg
  ./recmsg
  ```
- **Purpose**: Reads the message from the queue and then destroys the message queue.

## How It Works

1. `ftok("progfile", 65)` generates a unique key using the file `progfile`.
2. `msgget()` creates a new message queue or accesses an existing one using the key.
3. `msgsnd()` sends a message to the queue.
4. `msgrcv()` receives a message of type `1` from the queue.
5. `msgctl()` with `IPC_RMID` deletes the message queue after receiving.

## Requirements

- Linux-based system
