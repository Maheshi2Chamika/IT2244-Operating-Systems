# IT2244-Operating-Systems
Commands & Examples

1. pwd
   Description: Displays the current working directory.
   Usage:
     - pwd
   Purpose: Shows the full path of the current directory.

2. date +%d
   Description: Displays the current day of the month.
   Usage:
     - date +%d
   Purpose: Displays the day of the month as a number.

3. date +%A
   Description: Displays the full name of the current weekday.
   Usage:
     - date +%A
   Purpose: Displays the full weekday name (e.g., Monday).

4. date +%a
   Description: Displays the abbreviated name of the current weekday.
   Usage:
     - date +%a
   Purpose: Displays the abbreviated weekday name (e.g., Mon).

5. date +%B
   Description: Displays the full name of the current month.
   Usage:
     - date +%B
   Purpose: Displays the full month name (e.g., March).

6. date +%b
   Description: Displays the abbreviated name of the current month.
   Usage:
     - date +%b
   Purpose: Displays the abbreviated month name (e.g., Mar).

7. date +%Y
   Description: Displays the current year with four digits.
   Usage:
     - date +%Y
   Purpose: Displays the current year (e.g., 2025).

8. date +%y
   Description: Displays the current year with two digits.
   Usage:
     - date +%y
   Purpose: Displays the current year in two digits (e.g., 25).

9. date +%M
   Description: Displays the current minute.
   Usage:
     - date +%M
   Purpose: Displays the current minute (e.g., 37).

10. date +%H
    Description: Displays the current hour (24-hour format).
    Usage:
      - date +%H
    Purpose: Displays the current hour (e.g., 19).

11. date +%S
    Description: Displays the current second.
    Usage:
      - date +%S
    Purpose: Displays the current second (e.g., 27).

12. vi prgrm1.sh
    Description: Opens the file `prgrm1.sh` in the `vi` editor for editing.
    Usage:
      - vi prgrm1.sh
    Purpose: Opens `prgrm1.sh` to allow modifications or creation.

13. chmod 777 prgrm1.sh
    Description: Changes the permissions of the file `prgrm1.sh` to make it executable for everyone.
    Usage:
      - chmod 777 prgrm1.sh
    Purpose: Sets read, write, and execute permissions for the owner, group, and others.

14. ./prgrm1.sh
    Description: Executes the `prgrm1.sh` script.
    Usage:
      - ./prgrm1.sh
    Purpose: Runs the script `prgrm1.sh` that prompts the user for input and performs calculations.
